# 🚀 HLabs Dev

🔗 Live Demo: https://hlabs-dev.vercel.app/

HLabs Dev is a modern web application designed as a **developer portfolio** and a collection of **useful developer tools**. It focuses on performance, scalability, and clean UI/UX.

---

## ✨ Features

- 🧑‍💻 Showcase portfolio projects
- 🛠️ Built-in developer tools (formatters, utilities, etc.)
- ⚡ High performance with SSR / Edge deployment
- 🔐 Backend API with scalable architecture
- 🎨 Clean and modern UI
- 📱 Fully responsive design

---

## 🧰 Tech Stack

### Frontend
- ⚛️ Next.js + TypeScript
- 🎨 Tailwind CSS

### Backend
- 🟢 Node.js
- 🧩 NestJS (modular & scalable architecture)
- 🔷 TypeScript

### Database
- 🐘 PostgreSQL

### Deployment
- ☁️ Vercel (Frontend)
